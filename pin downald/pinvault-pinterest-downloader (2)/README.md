# PinVault — Pinterest HD Image & Video Downloader

One-click hover downloader for Pinterest images, GIFs, and videos (both progressive MP4 and adaptive HLS streams) at the highest available quality.

## How to Install in Chrome (Windows / macOS)

1. **Extract the ZIP file**: Right-click `pinvault-pinterest-downloader.zip` and choose **Extract All...** (Windows) or double-click it (macOS).
2. **Verify `manifest.json`**: Open the extracted folder and confirm `manifest.json` is directly inside it.
3. **Open Chrome Extensions**: Go to `chrome://extensions` in Google Chrome and enable **Developer mode** (top-right toggle).
4. **Load Unpacked**: Click **Load unpacked** and select the extracted folder containing `manifest.json`.

## How to Use

1. Open [Pinterest](https://www.pinterest.com/) and browse your feed, boards, or any Pin.
2. Hover over any image or video — a dark pill button (**HD** or **HD Video**) appears in the bottom-left corner.
3. Click it once to download the highest-resolution original file directly to your Downloads folder (`Downloads/Pinterest/`).
